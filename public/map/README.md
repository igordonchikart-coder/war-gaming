# Карта-подложка для гекс-редактора

Положите сюда изображение карты, которое рисуется **под** (или вместе с) гекс-сеткой.

## Приоритет загрузки в коде

1. `/map.webp` — полный локальный оригинал (`public/map.webp`, gitignored). **По умолчанию грузится as-is, без даунскейла.**
2. `/map/base.webp` — игровой экспорт в репозитории (~3072 px) — только если `map.webp` отсутствует
3. `/map/base-2048.webp` — запасной меньший вариант — только если оба выше недоступны

Качество мастера не урезается в рантайме. Опциональный тумблер **«Быстрая подложка»** в UI может сжать длинную сторону до 4096 px (для слабых машин); по умолчанию выключен.

## Рекомендуемый формат (для репо / fallback)

| Параметр | Рекомендация |
|----------|----------------|
| Формат | **WebP** (предпочтительно) или PNG/JPEG |
| Размер стороны | **2048–4096 px** по длинной стороне |
| Вес файла | желательно **&lt; 5 MB** |

Исходник в репозитории сейчас:

- `base.webp` — ~3072 px, fallback если нет локального `map.webp`
- `base-2048.webp` — запасной меньший вариант

Полный high-quality `public/map.webp` (десятки MB / 10k+ px) и `public/map.png` **не коммитятся**. Держите их локально; редактор подхватит `map.webp` автоматически в полном разрешении.

## Экспорт из Photoshop / большого WebP/PNG

1. Откройте исходник (PSD, полный WebP или PNG).
2. Для локальной работы: экспортируйте полный WebP → `public/map.webp` (качество не урезать).
3. Для репо-fallback: `Image → Image Size` → длинная сторона **2048–4096**, затем WebP → `public/map/base.webp`.
4. Тайлы: добавьте `tile-01.webp` и пропишите URL в `src/hex/mapImage.ts` → `MAP_TILE_URLS`.

## PSD

Файлы `.psd` браузер не рисует. Экспортируйте PNG/WebP по инструкции выше. `*.psd` в gitignore.

## Несколько тайлов

Если карта разрезана на части — кладите файлы сюда и добавляйте пути по одному в `MAP_TILE_URLS`. Загрузчик тянет их **последовательно**, не все сразу.

## Выравнивание в UI

1. **Автокалибровка** (один клик) — подгоняет оверлей под печатную flat-top сетку `map.webp` (`calibration.json`).
2. Или **Открыть файл** → `public/map/map-align-autocal.json`.
3. Доводка: **Scale X/Y**, **Калибровка 2 точки**.
4. Слои (карта / сетка / оба), опционально **Быстрая подложка**.

Погрешность автокалибровки ≈0.15 гекса (до ≈0.25 на дальних углах). Если слева ровно, а справа уезжает — Scale Y или 2 точки.

## Как проверить, что грузится полный map.webp

В статус-баре редактора должно быть примерно:

`Подложка FULL · /map.webp · 11731×9933 px`

(размеры — натуральные пиксели вашего файла). Если видите `/map/base.webp` или `/map/base-2048.webp` — локального `public/map.webp` нет. Если видите «даунскейл» — включён тумблер «Быстрая подложка».
