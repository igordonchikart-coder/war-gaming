# Карта-подложка для гекс-редактора

Положите сюда изображение карты, которое рисуется **под** (или вместе с) гекс-сеткой.

## Приоритет загрузки в коде

1. `/map.webp` — полный локальный оригинал (`public/map.webp`, часто gitignored если &gt; ~10 MB)
2. `/map/base.webp` — игровой экспорт в репозитории (~3072 px)
3. `/map/base-2048.webp` — запасной меньший вариант

## Рекомендуемый формат (для репо)

| Параметр | Рекомендация |
|----------|----------------|
| Формат | **WebP** (предпочтительно) или PNG/JPEG |
| Размер стороны | **2048–4096 px** по длинной стороне |
| Вес файла | желательно **&lt; 5 MB**, максимум без даунскейла в рантайме — **&lt; 10 MB** |

Исходник в репозитории сейчас:

- `base.webp` — ~3072 px, рабочая подложка для редактора / fallback
- `base-2048.webp` — запасной меньший вариант

Полный lossless/high-quality `public/map.webp` (десятки MB / 10k+ px) и `public/map.png` **не коммитятся**. Держите их локально; редактор подхватит `map.webp` автоматически.

## Экспорт из Photoshop / большого WebP/PNG

1. Откройте исходник (PSD, полный WebP или PNG).
2. `Image → Image Size` → длинная сторона **2048–4096**.
3. `File → Export → Export As…` → **WebP** (качество ~75–85) или PNG.
4. Сохраните как `public/map/base.webp` (замените существующий) **или** добавьте тайл `tile-01.webp` и пропишите URL в `src/hex/mapImage.ts` → `MAP_TILE_URLS`.

## PSD

Файлы `.psd` браузер не рисует. Экспортируйте PNG/WebP по инструкции выше. `*.psd` в gitignore.

## Несколько тайлов

Если карта разрезана на части — кладите файлы сюда и добавляйте пути по одному в `MAP_TILE_URLS`. Загрузчик тянет их **последовательно**, не все сразу.

## Выравнивание в UI

В редакторе: режим слоёв (карта / сетка / оба), **Fit width** или слайдеры **scale / offsetX / offsetY**.
